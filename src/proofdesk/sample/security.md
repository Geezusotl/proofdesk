# Security Basics

## Accounts and passwords

Every employee must use the Vaultwise password manager for work accounts. Multi-factor authentication is required on all accounts, and engineers with production access must use a hardware security key instead of a phone prompt. Passwords are never shared in chat or email.

## Laptops

Laptops lock automatically after 5 minutes without activity, and full-disk encryption must stay switched on. A lost or stolen device must be reported to security within 2 hours of noticing, even if it happened outside working hours. The security team can wipe a device remotely, and a prompt report is what makes that possible.

## Updates

Operating system and application updates must be installed within 7 days of release. Critical security patches must be installed within 48 hours. The IT desk sends a reminder when a device falls behind.

## Phishing

Suspicious emails are reported with the Report Phish button in the mail client, never forwarded. The security team investigates each report and replies within one business day. Employees who report a real phishing attempt are thanked in the monthly security note.

## Public networks and devices

The VPN must be switched on when working from a cafe, airport or other public network. Personal USB drives must not be plugged into company laptops. Guests use the guest Wi-Fi, which is separate from the office network.

## Data classes

Information is labelled public, internal, confidential or restricted. Restricted data, such as customer payment details, may never leave the production environment and must not be copied to laptops.
